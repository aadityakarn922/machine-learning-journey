# Machine Learning Journey

A personal repository documenting my journey of learning **Machine Learning**.

This repository contains my learning notes, practice code, experiments, and projects as I progress through different concepts and techniques.

## Objective

To build a strong foundation in Machine Learning through consistent learning, hands-on practice, and real-world projects.

## Repository Structure

| Folder | Topic | Contents |
| --- | --- | --- |
| `edausingunivariate/` | Univariate EDA | Distribution, spread and outlier analysis |
| `bivariateandmultivariate/` | Bivariate & Multivariate EDA | Correlation, pair plots, relationship study |
| `Statistics/` | Statistics | Chi-square tests and related hypothesis testing |
| `featureengineering/` | Feature Engineering | Encoding, scaling, transformers, column transformers, pipelines |
| `workingwithcsv/` | CSV Handling | Loading and wrangling tabular CSV data |
| `workingwithjson/` | JSON Handling | Parsing nested JSON structures |
| `fetchingapi/` | APIs | Fetching and working with REST API responses |
| `tensor_demo/` | Tensors | Tensor manipulation basics |
| `pandasprofilling/` | Profiling | Automated EDA reports via pandas-profiling |
| `TASKS/` | Practice Tasks | End-to-end exercises on Heart, Insurance and Placement datasets |

## Learning Path

1. **Data ingestion** — CSV, JSON and API sources
2. **Exploratory Data Analysis** — univariate, then bivariate and multivariate
3. **Statistics** — the tests that back up (or challenge) the visual read
4. **Feature Engineering** — encoding, scaling, transformation and pipelines
5. **Model building** — end-to-end task notebooks

## Setup

```bash
pip install pandas numpy matplotlib seaborn scikit-learn openai python-dotenv
```

Copy the environment template and fill in your own credentials where a script needs them:

```bash
cp .env.example .env
```
